# cargoservice-

Sistema distribuito e IoT per l'automazione del carico di una stiva con lo scopo di orchestrare, in sicurezza e in tempo reale, un robot mobile autonomo facendolo interagire con dispositivi esterni.

## Repository Structure

Il repository è organizzato in cartelle, una per ogni sprint. All'interno di ciascuna c'è il codice sorgente e il relativo report in PDF.


### [Sprint 0: Analisi Requisiti](#)
Vocabolario formale dei vincoli e modello formale Qak iniziale.

### [Sprint 1: Architettura Logica](#)
Sviluppo dell'architettura logica centrale e superamento del gap cartesiano per il movimento del robot.

### [Sprint 2: Distribuzione Rete](#)
Distribuzione di rete del sistema, tramite protocolli CoAP, HTTP e MQTT, introducendo sensori e LED simulati.

### [Sprint 3: Hardware Reale](#)
Passaggio finale all'hardware fisico, sostituendo i simulatori con un Raspberry Pi Pico W collegato a un vero Sonar e a un LED.
